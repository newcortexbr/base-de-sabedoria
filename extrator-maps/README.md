# extrator-maps

catálogo de ajuda do Extrator Maps (Extrator Google Maps), usado pelo chat de suporte com IA. público: cliente. todos os artigos têm `validacao: codigo-e-video`, exceto os de login/bloqueio, trocar senha, erros ao iniciar (só código).

## regra de verdade
- o código do Extrator (repositório `newcortexbr/extrator_maps`, commit `abc8267`, 21/10/2026) manda. os vídeos (`videos.json`) servem para a ordem dos passos, dicas e o "porquê".
- o PRD do repositório está desatualizado e não é fonte (ex.: validade de 15 dias, boas-vindas de 500).
- conflitos entre vídeo, código e artigos antigos: `interno/divergencias.md` (a pasta `interno/` não vai ao chat).
- guia curto de acesso na Área do Cliente: `area-do-cliente/ferramentas/extrator-maps.md`.
